# Project Recovery: Спасение продакшена «Три Топора»

Учебный проект по курсу «Автоматизация тестирования с помощью Selenium и Python».
Демонстрация работы с Git: фиксация проблемы, откат к стабильной версии, защита от мусора.

## Легенда

Кощей Бессмертный, DevOps-архитектор IT-королевства «Три Топора», закоммитил
кривой конфиг в `app-config.json` и сломал продакшен:

- 📱 Смартфоны у бояр разряжаются за 5 минут
- ☁️ Облака плывут вниз
- 🌊 Реки данных текут вспять
- 💸 Кэш испаряется на глазах

Команда спасения:
- **Василиса Премудрая** (тимлид) — руководит операцией
- **Серый Волк** (бэкенд) — предоставил бэкап с прошлой недели
- **Иван Царевич** (фронтенд) — помог с восстановлением

## Что было сделано

1. **Подготовка:** создана директория `project-recovery`, настроены имя и email в Git.
2. **Фиксация катастрофы:** создан сломанный `app-config.json` от Кощея, закоммичен как `Initial: damaged config from Koschey`.
3. **Откат к стабильной версии:** сломанный файл удалён, восстановлен рабочий конфиг из бэкапа Серого Волка, закоммичен как `Recovery: restored working config from backup`.
4. **Расследование:** изучена разница между коммитами через `git diff` и `git show`.
5. **Защита:** создан `.gitignore` для защиты от временных файлов, логов, секретов и личных файлов Кощея.
